# Marketplace Scanner V1
Modular LS-parts listing scanner with SQLite duplicate detection and a mobile-friendly Flask dashboard.

## Run
Python 3.11+:
`pip install -r requirements.txt`
`python scanner.py`
`python app.py`

The acquisition layer must use an authorized/permitted listing source. This project does not bypass logins, CAPTCHAs, anti-bot systems, or access controls.
